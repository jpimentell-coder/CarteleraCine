1. Abrir CarteleraCine.sln en Visual Studio
2. Presionar F5 o el botón verde
3. Elegir una opción del menú escribiendo su número y presionando Enter
 
 -1. Registrar función: Pide película, sala y precio, y guarda la función
 
 -2. Listar funciones: Muestra todas las funciones y el total de precios
 
 -3. Buscar función por Id: Pide un Id y muestra la función si existe
 
 -4. Actualizar precio:Pide un Id y un nuevo precio, y lo actualiza
 
 -5. Eliminar función: Pide un Id y elimina la función
 
 -6. Salir: Termina el programa
